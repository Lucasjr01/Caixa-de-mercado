# 🛒 Sistema de Caixa de Mercado

Este repositório foi criado com o objetivo de colocar em prática os conhecimentos adquiridos nas aulas de **Python** e **Git/GitHub** do professor Gustavo Guanabara (Curso em Vídeo). 

Mais do que um sistema finalizado, este espaço é o meu ambiente de estudos e evolução. Aqui eu testo minha lógica de programação e o versionamento de código em paralelo com o curso, sempre que aprender algo novo e que faça sentido no meu codigo o farei.

## 🚀 O que estou praticando?

**No código (Python):**
- Desenvolvimento da lógica de programação
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Entrada e saída de dados

**No versionamento (Git e GitHub):**
- Comandos essenciais de terminal (`push`, `pull`, `commit`)
- Histórico de versões e fluxo de trabalho
